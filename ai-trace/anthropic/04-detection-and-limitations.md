# 04 — Detection and limitations

> *The absence of a mark is not proof of a human author, just as the presence of one is not proof that the whole text is artificial. Between black and white lies the territory where most real texts live.*

## 1. How detection works

Detecting a text mark is a **statistical, keyed procedure**. In general terms:

1. the detector reproduces the sequence of pseudorandom values the sampling scheme would have produced, using the secret key $K$ and each token's context;
2. it reconstructs the token→position assignment (in MirrorMark's case, *replaying* CABS);
3. it computes an **aggregated statistic** over the tokens (sum of $u$, number of "greens", reflection *score*, etc.);
4. it compares against a threshold: above, *marked* is declared; below, not.

The result is a **probabilistic verdict**, not a deterministic proof. Anthropic confirms that detection "indicates that the content *may* have been processed by Claude", and that it will publish the detection mechanisms in forthcoming technical documentation. The European Code of Practice also obliges **sharing detection capability with third parties**.

## 2. The false precision of detection

Every detection system defines two errors, which are **inversely coupled**:

- **false positive (FPR)**: human text declared marked;
- **false negative**: marked text not detected.

The modern-mark literature is typically evaluated by **fixing the FPR at 1 %** and measuring the achievable TPR: MirrorMark reports up to 11 % more detected texts than previous methods *at that same FPR*. Choosing the threshold $\theta$ is therefore a **policy** decision: a more aggressive detector catches more AI text but condemns more humans; a more conservative one protects humans but lets more synthetic text through. Whoever sets the threshold decides who bears the errors.

## 3. C2PA and tamper detection

For **files** (`.svg`, `.png`, `.jpg`), verification is not statistical but cryptographic: the **digital signature** of the C2PA metadata is verified.

- If the signature is valid, the file was processed by Claude and **has not been altered** since.
- If the file was edited and re-saved so that metadata was preserved but content changed, the signature **does not verify**: a sign of tampering.
- If the metadata was removed (format conversion, re-saving, screenshot, upload to a social network that strips it), **the proof disappears**: the file is left without a signal, which does not imply it is human.

C2PA is, in this sense, more transparent than the text mark: the signature **attests and can be broken**, while the watermark **degrades silently** until it becomes undetectable without anyone noticing.

## 4. Limits recognized by Anthropic

Anthropic documents the frontiers of its own system with honesty:

1. **The mark is not conclusive.** A marked text does not imply Claude is the original author: Claude is often used to *proofread*, *translate*, *summarize* or *convert* human material. The content may have changed after processing (fragments, blends).
2. **The absence of a mark does not prove human authorship.** The text may carry no detectable mark if:
   - it was generated by a model released before marking support;
   - it was **heavily edited, paraphrased, translated, or mixed** into other writing;
   - it is a **very short passage** (too little statistical signal for a reliable decision);
   - the file's metadata was stripped through conversion, re-saving, or screenshots;
   - it comes from a platform, feature, or file type without a given marking type.
3. **Detection is a signal, not a certificate.** The probabilistic verdict coexists with both errors.

## 5. The short-text paradox

There is a structural relationship between **length and detectability**. The statistical signal is aggregated over tokens; if the text is very short, the variance of the statistic under the null hypothesis is high and the separation margin between *marked* and *unmarked* shrinks. In other words: **the watermark protects long texts and abandons brief ones**. A three-line excerpt can escape detection not because it carries no mark, but because the mark cannot accumulate enough evidence. This is the only design limitation the user cannot exploit at will: the detector imposes it alone.

## 6. Critical reading

The combination of text mark + C2PA covers two different registers of authorship: **statistical attribution** (did the text come from Claude?) and **cryptographic attestation** (is this file exactly what Claude produced?). The first is robust but probabilistic; the second is deterministic but fragile against metadata loss. The weak link of the whole system is not technical but social: **who is entitled to consult the detector, and with what threshold**. The transparency promised by Article 50 does not by itself answer that question; it moves it.
